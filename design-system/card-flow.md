# 카드뉴스 자동 생성 흐름 (card-flow.md)

> **이 문서는 무엇인가요?**
> 주제 하나를 넣으면 **인스타그램 카드뉴스 한 덱(여러 장)** 이 나오도록, *내용을 어떤 순서·몇 장으로 짤지*를 정한 **기획 규칙**입니다.
> 짝꿍 문서인 [`design.md`](./design.md)가 **"어떻게 보이는가"(색·글자·배치)** 를 정한다면, 이 파일은 **"무엇을 어떤 흐름으로 말하는가"(내용·장수)** 를 정합니다.
>
> 자동 생성을 돌릴 때 이 문서(특히 §8 프롬프트)를 그대로 쓰면 됩니다. **이미지는 맨 마지막** — 먼저 §5의 **카드 구성표**부터 만듭니다.

| 문서 | 정하는 것 | 비유 |
|---|---|---|
| [`design.md`](./design.md) | 보이는 규칙 (색·타이포·구도·NB2) | 옷의 **디자인** |
| **`card-flow.md`** (이 파일) | 내용 흐름 규칙 (입력→흐름→장수→구성표) | 옷의 **패턴(본)** |

---

## 0. 한눈에

```
입력 4개 ──▶ 흐름 짜기 ──▶ ⭐카드 구성표(표/JSON) ──▶ (사람 확인) ──▶ 이미지(NB2)
주제·타깃·톤·최종행동      Hook→Pain→Steps×N→Result→CTA        ← 지금 여기까지가 1차 산출물
```

- **흐름:** Hook → Pain → **Steps(내용에 맞게 N장)** → Result → CTA
- **장수:** 내용이 정한다. 단계 2개면 2장, 5개면 5장. 총 장수 = **N + 4**. 5장이면 5장, 단계 많으면 7·8·9·10장도 OK.
- **각 장:** **큰 제목 + 짧은 본문** 둘 다. (단 **Hook은 큰 제목 하나만** 넣어도 됨)
- **절대 규칙:** **이미지 만들기 전에 "카드 구성표"부터** 보여준다. (→ §4)

---

## 1. 입력 4개 (이게 모든 걸 결정한다)

| 입력 | 뜻 | 왜 필요한가 | 예시 |
|---|---|---|---|
| **주제** | 카드뉴스로 만들 주제 또는 뉴스기사 내용 | 무엇을 말할지 | "사회초년생 첫 적금 시작하기" |
| **타깃** | 이 카드뉴스를 볼 사람 | 누구 눈높이로 쓸지(어휘·예시·고민) | "막 취업한 20대, 저축 처음" |
| **톤** | 말투·태도 | 문장 스타일 통일 | "현실적·직설적, 초보자도 그대로 따라하게" |
| **최종행동** | 보고 나서 이해/행동했으면 하는 것 | **CTA가 향할 목표** | "오늘 자유적금 1개 개설 + 자동이체" |

> **톤 기본값(이 프로젝트):** *현실적·직설적, 단 초보자도 따라할 수 있게.*
> → 추상적 조언("꾸준히 하세요") 금지. **구체적인 행동·숫자·순서**로. (→ §6)

---

## 2. 흐름: Hook → Pain → Steps(×N) → Result → CTA

각 역할을 우리 카드 종류(`CardKind = 'cover' | 'body' | 'cta'`, `design.md §4`)에 매핑합니다.

| # | 역할 | 목적 | `kind` | 큰 제목 | 짧은 본문 | 장수 |
|---|---|---|---|---|---|---|
| 1 | **Hook** | 멈추게 하는 한 방 | `cover` | ✅ 필수 | ⬜ **생략 가능** | 1장 |
| 2 | **Pain** | "이거 내 얘긴데" 공감·문제 | `body` | ✅ | ✅ | 1장 |
| 3…n | **Steps** | 해결을 **단계로** | `body` | ✅ | ✅ | **N장(가변)** |
| n+1 | **Result** | 그래서 얻는 변화·보상 | `body` | ✅ | ✅ | 1장 |
| n+2 | **CTA** | **최종행동**을 하게 | `cta` | ✅ | ✅ | 1장 |

- **Hook:** 큰 제목 하나로 충분. 호기심·공감·반전(`design.md §1.5`의 후킹 컨벤션). 본문을 굳이 안 넣어도 됨.
- **Pain:** 타깃이 겪는 진짜 불편/손해를 한 장면으로. 해결책 아직 X — 긁기만.
- **Steps:** 아래 §3 규칙으로 **단계 수만큼** 풀어 쓴다. **한 장에 두세 단계 압축 금지.**
- **Result:** 단계를 다 했을 때의 비포→애프터(숫자로 보이면 최고).
- **CTA:** **최종행동을 그대로** 시킨다("지금 ○○ 하세요"). 핸들·해시태그 포함.

---

## 3. 장수는 "내용"이 정한다 (Steps 가변)

- **단계 = 장.** 단계가 2개면 Step 2장, 3개면 3장, 5개면 5장. **절대 한 장에 욱여넣지 않는다.**
- **공식:** `총 장수 = 1(Hook) + 1(Pain) + N(Steps) + 1(Result) + 1(CTA) = N + 4`

| 단계 수 N | 총 장수 | 예 |
|---|---|---|
| 1 | **5장** | 핵심 행동이 하나뿐인 주제 |
| 2 | 6장 | |
| 3 | 7장 | |
| 4 | 8장 | |
| 5 | 9장 | |
| 6 | 10장 | 절차가 긴 주제 |

- **5장으로 충분하면 5장.** 억지로 늘리지 않는다(빈 단계 만들기 금지).
- 단계가 6개를 넘기면(총 10장↑) **단계를 합쳐 굵직하게 묶어 N을 6 이하(총 10장 이하)로** 만든다. (**5~10장 범위를 지킨다** — 한 덱이 너무 길면 끝까지 안 본다.)
- 주제가 "단계형"이 아니면(뉴스 요약·인사이트 등) Steps 자리에 **핵심 포인트 1~3장**을 넣는다(각 포인트 = 1장).

> ⚠️ **현재 코드 상태:** 생성기(`lib/ai.ts`)는 아직 **5장 고정**입니다. 이 가변 길이 흐름은 *설계*가 먼저 확정된 것이고, 생성기·페이지번호(`0n / 0T`) 가변화는 다음 작업입니다(`design.md §5`). **카드 구성표(텍스트)는 지금도 이 규칙대로 가변으로** 만듭니다.
>
> 스코프를 헷갈리지 마세요: **구성표 = 가변(이 문서 기준)**, **생성기 런타임 = 5장 고정**. `design.md §5`의 "본문 3장 안에서 압축"은 *현재 생성기 출력에만* 적용되는 임시 가이드입니다.

---

## 4. ⭐ 절대 규칙: 이미지보다 "카드 구성표"가 먼저

**순서를 어기지 않는다.**

1. 입력 4개 받기 →
2. **카드 구성표 출력**(아래 §5의 표 + JSON) →
3. 사람이 보고 **OK / 수정** →
4. *그 다음에* 표지·배경 **이미지 생성(Gemini 나노바나나2 NB2, `design.md §8`)**.

> 왜? 구성(제목·본문·장수)이 틀리면 이미지를 아무리 잘 뽑아도 다시 만들어야 한다. **글이 먼저, 그림은 나중.** 토큰·시간 낭비를 막는다.

## 5. 카드 구성표 형식

### 5.1 사람이 보는 표 (마크다운)

| # | 역할 | kind | 라벨 | 큰 제목 (≤2줄) | 짧은 본문 |
|---|---|---|---|---|---|
| 1 | Hook | cover | (카테고리) | … | (생략 가능) |
| 2 | Pain | body | 본문 | … | … |
| 3 | Step 1 | body | STEP 1 / N | … | … |
| … | Step n | body | STEP n / N | … | … |
| n+1 | Result | body | 본문 | … | … |
| n+2 | CTA | cta | CTA | … | … (+ 해시태그) |

- **큰 제목:** 2줄 이내, 어절 단위 줄바꿈(`keep-all`) — 줄바꿈은 `\n`로 표기. (`design.md §2.1`)
- **짧은 본문:** 1~2문장, 짧게. (`design.md §2.2`)
- **라벨:** Hook=카테고리 한 단어 / Step=`STEP n / N` / 나머지=`본문`·`CTA`.

### 5.2 자동화용 JSON 스키마

```jsonc
{
  "meta": {
    "topic":  "사회초년생 첫 적금 시작하기",
    "target": "막 취업한 20대, 저축 처음",
    "tone":   "현실적·직설적, 초보자도 따라하게",
    "goal":   "오늘 자유적금 1개 개설 + 자동이체",
    "total":  8            // = N + 4 (내용이 정함)
  },
  "cards": [
    { "idx": 0, "role": "hook",   "kind": "cover", "label": "재테크",      "title": "월급은 들어오는데\n왜 안 모일까", "body": "" },
    { "idx": 1, "role": "pain",   "kind": "body",  "label": "본문",        "title": "...", "body": "..." },
    { "idx": 2, "role": "step",   "kind": "body",  "label": "STEP 1 / 4", "title": "...", "body": "...", "step": 1, "stepTotal": 4 },
    // ... step 2,3,4 ...
    { "idx": 6, "role": "result", "kind": "body",  "label": "본문",        "title": "...", "body": "..." },
    { "idx": 7, "role": "cta",    "kind": "cta",   "label": "CTA",         "title": "...", "body": "...", "hashtags": ["#사회초년생","#첫적금"] }
  ]
}
```

> `role`은 이 흐름의 역할, `kind`는 렌더러(`CardFace.tsx`)가 쓰는 카드 종류 — **둘 다** 둔다(렌더 호환 + 의미 보존).

## 6. 톤 가이드 — 현실적·직설적 + 초보자 따라하기

| ✅ 이렇게 | ⛔ 이렇게 말고 |
|---|---|
| "월급날 **다음 날** 자동이체 걸기" | "꾸준히 저축하는 습관을 들이세요" (추상적) |
| "실수령의 **10%**, 30만이면 3만 원부터" | "형편에 맞게 적당히" (모호) |
| "통장 **2개**로 쪼개기 — 안 섞이게" | "관리에 신경 쓰세요" (행동 없음) |
| "지금 은행앱 → 자유적금 → 5분이면 끝" | "여유 될 때 시작해보세요" (미룸 유발) |

- **숫자·순서·도구명**을 넣는다(따라할 수 있게).
- 한 장 = **한 메시지**. 욕심내서 두세 개 넣지 않는다.
- 직설적이되 **비난·과장·허위는 금지**(`design.md §2.1`). 타깃을 깎아내리지 말고 "같이 해보자" 톤.

---

## 7. 제목·본문 작성 규칙 (design.md 인용)

- 큰 제목: **최대 2줄**, 한 줄 6~12자, 어절 단위 줄바꿈, 핵심어 1곳만 강조(`**굵게**`/`==형광펜==`). (`design.md §2.1`)
- 짧은 본문: 한 줄 ≤ 약 20자, 1~3줄, 한 문장 요지. (`design.md §2.2`)
- 제목 크기·본문 크기·위치는 **전 장 동일**(`design.md §3`). 구성표는 *글*만 정하고, *보이는 값*은 design.md가 강제.

## 8. 자동 생성 프롬프트 템플릿 (복붙용)

> LLM(텍스트 모델)에게 그대로 주면 카드 구성표가 나옵니다. 입력 4개만 채우세요.

```text
너는 한국어 인스타그램 카드뉴스 기획자다. 아래 입력으로 "카드 구성표"를 만든다.

[입력]
- 주제: {{주제}}
- 타깃: {{타깃}}
- 톤: {{톤}}   (예: 현실적·직설적, 초보자도 그대로 따라하게)
- 최종행동: {{최종행동}}

[흐름] Hook → Pain → Steps(내용에 맞게 N장) → Result → CTA

[규칙]
1) Hook: 큰 제목 하나. 본문은 없어도 된다.
2) Steps: 내용상 단계 수만큼 장을 만든다(2개면 2장, 5개면 5장). 한 장에 여러 단계를 압축 금지.
3) Hook을 제외한 모든 장: 큰 제목 + 짧은 본문 둘 다 넣는다.
4) 총 장수 = N + 4. 내용에 맞게 정한다(5장이면 5장, 단계 많으면 7~10장). 억지로 늘리지 마라.
5) 큰 제목: 2줄 이내, 어절 단위 줄바꿈(\n). 짧은 본문: 1~2문장, 짧고 구체적으로.
6) 톤: 현실적·직설적. 추상적 조언 금지 — 숫자·순서·도구명 등 따라할 행동으로 써라.
7) CTA는 "최종행동"을 지금 바로 하게 만든다. 해시태그 3~5개.
8) ⚠️ 이미지/그림을 만들지 마라. 지금은 "카드 구성표"(아래 JSON)만 출력한다.

[출력] card-flow.md §5.2 의 JSON 스키마(meta + cards[])로만 답한다.
```

> 출력 JSON을 받으면 사람이 표(§5.1)로 검토 → OK 후에 이미지(NB2) 단계로 넘어간다.

## 9. 워크드 예시 (실제 카드 구성표)

**입력**
- 주제: 사회초년생 첫 적금 시작하기
- 타깃: 막 취업한 20대 사회초년생 (저축 처음, 모으는 법 모름)
- 톤: 현실적·직설적, 초보자도 그대로 따라하게
- 최종행동: 오늘 안에 자유적금 1개 개설 + 월급날 자동이체 걸기

**카드 구성표 (4단계 → 총 8장)**

| # | 역할 | kind | 라벨 | 큰 제목 | 짧은 본문 |
|---|---|---|---|---|---|
| 1 | Hook | cover | 재테크 | 월급은 들어오는데\n왜 안 모일까 | — |
| 2 | Pain | body | 본문 | 돈은 '남으면'\n안 모인다 | 쓰고 남은 걸 모으려니 매달 0원. 순서가 틀렸어요. |
| 3 | Step 1 | body | STEP 1 / 4 | 금액부터\n정하기 | 실수령의 10%면 충분. 300만이면 30만이 아니라 3만부터 OK. |
| 4 | Step 2 | body | STEP 2 / 4 | 통장 2개로\n쪼개기 | 월급통장 ≠ 저축통장. 같이 두면 무조건 새어나가요. |
| 5 | Step 3 | body | STEP 3 / 4 | 자동이체\n걸기 | 월급날 '다음 날'로 예약. 손대기 전에 빠져나가게. |
| 6 | Step 4 | body | STEP 4 / 4 | 6개월 뒤\n금액 올리기 | 익숙해지면 10%→15%. 처음부터 무리하면 포기해요. |
| 7 | Result | body | 본문 | 1년이면\n통장에 360만 | 안 쓰던 돈이 비상금으로. 갑자기 돈 나가도 덜 흔들려요. |
| 8 | CTA | cta | CTA | 오늘 통장 1개\n만들고 시작 | 은행앱 → 자유적금 → 자동이체. 5분이면 끝나요.<br>#사회초년생 #첫적금 #돈모으기 #자동이체 #짠테크 |

- 단계가 **4개라서 Step이 4장** — 압축하지 않음. 총 `4 + 4 = 8장`.
- Hook만 제목 하나, **나머지는 제목+본문 둘 다.**
- 톤: "10%·3만·다음 날·5분"처럼 **숫자·행동**으로 → 초보자가 그대로 따라함.
- CTA가 **최종행동("오늘 개설+자동이체")** 을 그대로 시킴.

> 이 표를 OK하면 → 각 장 배경 이미지를 **NB2**로 생성(`design.md §8`). 그 전엔 이미지 만들지 않음.

## 10. 생성 전 체크리스트

- [ ] 입력 4개(주제·타깃·톤·최종행동)가 다 있는가?
- [ ] 흐름이 Hook → Pain → Steps(×N) → Result → CTA 인가?
- [ ] **단계 수 = Step 장수**인가? (한 장에 압축 안 했는가?)
- [ ] 총 장수가 내용에 맞는가? (빈 단계로 억지로 늘리지 않았는가?)
- [ ] **Hook 빼고 모든 장에 제목+본문 둘 다** 있는가?
- [ ] 제목 2줄 이내·본문 짧게(`design.md §2`)인가?
- [ ] 톤이 현실적·직설적 + 초보자가 따라할 **구체 행동**인가?
- [ ] CTA가 **최종행동**과 일치하는가?
- [ ] **이미지보다 카드 구성표를 먼저** 냈는가? ✅
