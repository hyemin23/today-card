05 — Consistency

일관성 규칙 (전 장 동일)

독자가 "5장"이 아니라 "한 템플릿"으로 느끼게. 한 번 정하고 전 장에 똑같이. (값은 components/studio/CardFace.tsx 기준)

항목값규칙
제목 크기round(titleBase × fontScale × sizeBump) · 4:5 sizeBump 1.4전 장 동일. fontScale(0.7~1.5)는 꼭 필요할 때 한 단계만
제목 스타일800 / -.035em / line-height 1.16강조어만 900
본문 크기round(15 × sizeBump) / 행간 1.6 / opacity .85전 장 동일
줄바꿈최대 2줄 · keep-all · 어절 단위 · pre-line전 장 동일
위치 align3×3 그리드, 기본 '6'(왼쪽 아래)전 장 동일
폰트 / 팔레트 / 포인트색덱당 1 / 1세트 / 1색장마다 바꾸지 않음
06 — Do / Don't

레퍼런스 활용 · 복제 금지

레퍼런스는 규칙(원리)을 배우는 자료입니다. 결과물을 베끼는 게 아닙니다.

가져와도 되는 것 (원리)

  • 4:5 풀블리드 + 왼쪽 아래 앵커
  • 고대비 흑/백 + 포인트 1색
  • 두꺼운 산세 2줄, keep-all, 스크림
  • 후킹 제목 컨벤션(.zip / 고백형 / 질문형)
  • "장당 장치 1개" · 일관 그리드

그대로 베끼면 안 되는 것

  • 남의 로고·워드마크·핸들 (상표 침해)
  • 남의 사진 그대로 사용 (저작권 침해)
  • 남의 문구 토씨까지 복사
  • 시그니처 장치 1:1 모사
  • → 우리 사진·우리 팔레트·우리 카피로 재현
07 — Image API

이미지 생성은 Gemini 나노바나나 2(NB2)만

카드 배경/표지 이미지를 만드는 모든 API 호출은 오직 NB2만 사용합니다. (Imagen·DALL·E·Midjourney·SD 금지)

구분모델위치
나노바나나 (NB1)gemini-2.5-flash-image이전 기본값
나노바나나 2 (NB2)gemini-3-pro-image-preview ← 사용IMAGE_MODEL · lib/image.ts
텍스트/문구/해시태그 (별개)gemini-2.5-flashlib/ai.ts · 이 규칙 미적용
설정 — .env.local 에 IMAGE_MODEL=gemini-3-pro-image-preview. 프롬프트엔 항상 글자·로고·실존인물 금지 + 하단 어둡게(흰 헤드라인 가독성)를 박습니다. 키에 NB2 접근 권한이 없으면 IMAGE_MODEL을 가용한 ID로 교체하세요.
